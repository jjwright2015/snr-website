# SNR brand assets

Original league logo files (designed by Harpoon Design), added Oct 30, 2026.
Each design comes as SVG (best: sharp at any size), PNG (transparent background) and PDF.
The Illustrator master files (`.ai`, ~28 MB) are kept in the league admin's Google Drive, not here.

| Design | Shape | Use it for |
|---|---|---|
| SNR Logo 1 / SNR Logo 1 invert | Wide badge, yellow "Saturday Night", dark | Website header, graphics, PDFs (Logo 1 for light backgrounds, invert for dark) |
| SNG Logo 2 / SNR Logo 2 invert | Wide badge, white "Saturday Night" | Same as Logo 1, alternate color |
| SNR Logo BW / BW invert | Wide badge, black & white | Print, one-color uses |
| SNR Sticker / Sticker invert | Long horizontal wordmark with tire | Banners, headers, thin strips |
| SNR avatar 1 / Avatar 1 invert | Round "SNR" on checkered flag | Profile pictures, Discord, app icon |
| SNR Avatar 2 / Avatar 2 invert | Round "SNR" over a tire | Profile pictures |
| Artboard 23 | Tire + checkered flag artwork, no text | Background art |

`app-icon/`: the round avatars with the outer ring removed, for full-bleed app icons (Pick'em installable app).
Colors: yellow `#eadc5a`, dark gradient `#334353` to `#000000`, white.
